Спроектировать и реализовать серверную часть приложения, имитирующего базовые функции ящика электронной почты (e-mail клиента), с использованием языка Python и веб-фреймворка Django.

Реализация бизнес-логики: Написание контроллеров для обработки действий пользователя:

1. Отправка письма (создание записи в БД).

2. Получение списка входящих/исходящих писем.

3. Просмотр содержимого конкретного письма (с отметкой о прочтении).

4. Перемещение писем между папками (например, в «Корзину» или «Архив»).

5. Удаление писем.
